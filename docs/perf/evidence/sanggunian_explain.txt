NOTE ON VECTOR SIMILARITY QUERY (<=>):
--------------------------------------------------
Audit Finding: No SQL pgvector similarity query (e.g. `Sentence.embedding_dapt <=> ...`) is executed by the Sanggunian endpoint.
Instead, the endpoint fetches raw embedding vectors from PostgreSQL columns into Python, and executes cosine similarity inside `RobustAligner.compute_semantic_scores` in NumPy.
Therefore, the database queries are exact tabular filter scans rather than pgvector HNSW/IVFFlat index scans.
